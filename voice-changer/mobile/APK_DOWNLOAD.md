## 📲 安装说明

### 步骤 1: 允许未知来源

**Android 8.0+**:
- 设置 → 应用权限 → 安装未知应用
- 允许浏览器或文件管理器

**Android 7.0 及以下**:
- 设置 → 安全 → 未知来源
- 勾选"允许"

### 步骤 2: 安装 APK

**方法 1: 直接点击**
- 在手机上下载 APK
- 点击下载完成通知
- 点击"安装"

**方法 2: USB 传输**
- 用数据线连接手机和电脑
- 复制 APK 到手机
- 在手机上打开文件管理器
- 找到 APK 并点击安装

**方法 3: ADB 安装**
```bash
adb install VoiceChanger-2.1.4-debug.apk
```

## ⚙️ 使用教程

### 首次启动

1. **授予权限**
   - 麦克风权限（必需）
   - 存储权限（保存模型）

2. **下载模型**
   - 应用内点击"下载模型"
   - 选择喜欢的音色
   - 等待下载完成

3. **开始变声**
   - 选择音色模型
   - 调节音调（可选）
   - 按住"录音"按钮说话
   - 松手听变声效果

### 功能说明

| 功能 | 说明 |
|------|------|
| 音色选择 | 切换不同声音模型 |
| 音调调节 | -24 到 +24 半音 |
| 音量控制 | 0-200% 增益 |
| 实时监听 | 说话时实时听到变声 |

## ❓ 故障排查

### Q1: 无法安装

**原因**: 存储空间不足或权限问题

**解决**:
- 确保 500MB+ 可用空间
- 在设置中允许未知来源

### Q2: 应用闪退

**原因**: 权限未授予

**解决**:
- 设置 → 应用 → Voice Changer → 权限
- 授予麦克风权限

### Q3: 录音无声

**原因**: 模型未下载

**解决**:
- 在应用内下载模型
- 或手动放入 `models/` 目录

### Q4: 延迟太高

**优化**:
- 关闭后台应用
- 连接充电器（避免降频）
- 使用耳机监听
